# AI招聘助手

把 JD 和简历交给 AI，快速筛出「谁值得推进」。

在线体验：https://shiraishigm0120-commits.github.io/ai-recruiter-assistant/

## 产品定位

一个「简历预筛判断器」：HR 在招聘网站上看到简历，粘贴进来，AI 秒出「分数 + 技能缺口 + 一句话点评」，快速判断哪些人值得推进到招聘系统（如 Moka）。

## 效果截图

> 截图需要你手动添加，建议截取以下 3 个画面：
> 1. **工作台** — 已有岗位列表，展示搜索框 + 任务卡片
> 2. **匹配结果页** — 候选人排序列表，展示打分 + 硬条件对照 + 推进/淘汰按钮
> 3. **候选人详情页** — 展示分数、硬条件、技能缺口、凭什么行、简历原样

## 使用流程

1. **新建岗位**：填岗位名称 + JD
2. **进入岗位**：粘贴简历（文字 / 截图），或上传文件（PDF / Word / 图片 / 文本）
3. **开始匹配**：AI 打分排序，结果页显示「判断条 + 简历原样」
4. 历史筛选自动留存，可随时回看

## 支持的文件格式

| 格式 | 解析方式 |
|------|---------|
| PDF | pdf.js 提取文字 |
| Word (.docx) | mammoth 解析 |
| 图片 (png/jpg/…) | OCR 识别 |
| 纯文本 (.txt / .md) | 直接读取 |
| 粘贴文字 / 截图 | 直接读取 / OCR |

> 注：老格式 `.doc`（非 `.docx`）是二进制，浏览器无法解析，请另存为 `.docx` 或 PDF。

## 打分模式

| 模式 | 说明 |
|------|------|
| 演示模式（默认） | **内置关键词评分，无需网络，打开即用**。所有数据不出本机 |
| DeepSeek 真模型 | 在「设置」中配置 API Key 或代理地址即可启用，AI 精准打分 + 生成点评 |

## 接 DeepSeek 提升准确度（可选）

默认使用内置演示模式（关键词评分，无需网络）。如需更精准的 AI 打分：

1. 产品右上角「设置」→ 在「DeepSeek API Key」填入你的 Key → 保存
2. 或者部署 Cloudflare Worker 代理（见 `worker.js`），在「代理地址」填入 Worker URL

## 本地运行

直接双击 `index.html` 用浏览器打开即可。

## 数据与隐私

- 岗位、简历、筛选历史**全部存在你本机浏览器**（localStorage），不联网、不上传服务器。
- 默认演示模式，所有数据不出本机，无需网络。只有主动在「设置」中配置了 DeepSeek Key 或代理地址时，简历文字才会发给 DeepSeek 用于打分。
- 换设备或清缓存前，用设置里的「导出数据」备份，再到新设备「导入数据」。

## 文件说明

- `index.html` — 产品（单文件，5 页面）
- `lib/` — 本地化依赖（pdf.js、mammoth.js，不依赖国外 CDN）
- `worker.js` — Cloudflare Worker 代理（接真 DeepSeek 用）
